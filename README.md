# Angular7App

**Repository Description**  
This repository contains an Angular application generated using Angular CLI. The project serves as a base Angular setup that can be extended to build feature‑rich web applications, including dashboards and layout‑based user interfaces.

This application structure supports integration with UI layout components such as the Syncfusion Angular Dashboard Layout to create structured and dynamic dashboard experiences.

## Project Overview
The purpose of this project is to provide a foundational Angular application scaffolded using Angular CLI. It can be used to build applications that include grid‑based layout components, interactive dashboards, and modular UI functionality.

## Features
- Angular CLI–generated project structure  
- Development server with live reload  
- Component‑based application architecture  
- Configured workflows for building and testing Angular applications  

## Prerequisites
Ensure the following tools are installed before working with this project:
- NodeJS  
- Angular CLI  
- Visual Studio Code  

## Installation and Running the Application

### Development Server
Start the Angular development server using:
```bash
ng serve
```
Navigate to: `http://localhost:4200/`<br>
The application will automatically reload if you change any of the source files.
### Code Scaffolding
Generate new Angular components or other building blocks using:
```bash
ng generate component component-name
```
You can also generate directives, pipes, services, classes, guards, interfaces, enums, and modules.
### Build
Build the project using:
```bash
ng build
```
The build artifacts will be stored in the `dist/` directory. Use the `--prod` flag for a production build.

## Testing
- **Unit Tests:** Run ng test to execute unit tests via [Karma](https://karma-runner.github.io).
- **End‑to‑End Tests:** Run ng e2e to execute end‑to‑end tests via [Protractor](http://www.protractortest.org/).
